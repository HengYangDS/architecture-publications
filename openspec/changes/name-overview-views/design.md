# Design

## Context

See proposal.md for the motivation. The AIGW overview asks the model's question
of how operator intent becomes guarded native client projections. The ETHOS
overview asks the model's own question of how one change becomes a proven
commit on the accepted branch, through its lane, lease, proof and landing.

## Goals / Non-Goals

**Goals:**

- Each overview is named by what it shows on its poster and on the page.

**Non-Goals:**

- Changing what a model asserts: components, relations, details, sources, pins
  and questions stay as they are.
- A check that refuses generic titles: no fixed word list tells a title that
  names its view from one that does not, so review keeps that judgement.

## Decisions

- **Name the path the overview follows.** "From intent to guarded projections"
  and "One change, from lane to landing" name each overview's start and end,
  as the publisher's own edition names its overview "One build, end to end".

## Risks / Trade-offs

- [A longer title takes another line on a poster head] → The publisher refuses
  a page it cannot balance; building both works is the check.

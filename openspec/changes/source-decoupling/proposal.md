## Why

Architecture authoring must not add diagram code, tests or contracts to ETHOS
or AIGW. The independent publication repository owns editorial choices and
artwork, while original repositories retain their product meaning.

## What Changes

- Preserve selected ETHOS and AIGW editorial inputs and unique artwork.
- Produce generic Publisher inputs outside source repositories.
- Bind selected source Git revisions and member digests; keep source products
  read-only and accepted output predecessors unchanged.

## Capabilities

### New Capabilities

- `publication-inputs`: pinned read-only source selection and independently
  owned editorial input for qualified architecture publication.

## Impact

This repository owns authored inputs, source-specific adaptation and publication
checks. It depends on Publisher's public contracts, not source-repository
exporters, package installation or reverse imports.

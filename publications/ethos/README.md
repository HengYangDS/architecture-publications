# ETHOS Architecture

This independent editorial work retains exact original design and artwork from
[source.json](source.json). ETHOS must not own a diagram exporter, publication
package, editorial contract or drawing test. This preservation alone does not
prove that the separate source-removal transition has finished.

- [Design](design/declaration.json): preserved assertions, provenance and visual obligations.
- [Interactive artwork](artwork/interactive/edition.json): original page definitions and bindings.
- [Static artwork](artwork/static/edition.json): original independently composed poster inputs.

Existing source locators record the preserved source revision. They are not
current ETHOS files or implementation claims. Source-specific adaptation belongs
to this editorial work; Publisher's generic public contracts remain unchanged.
Accepted delivery files are preserved and are not regenerated by this migration.

Original executable static adapters are retained at the `preservationCommit`
in `source.json`, with their exact member digests. They are not active files:
their removed integration dependencies must not become a live compatibility
layer here. Remaining static edition and metrics data are preservation input,
not a claim that the former composition can currently be rebuilt.

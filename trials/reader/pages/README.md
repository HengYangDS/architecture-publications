# The pages of the fourth arm

One page for each repository of the reader experiment, stating its constraints, processes and decisions, each
statement with the file and lines that say it. Each was written on 2026-11-14 by one isolated holder under
[the brief](brief.md) through `author-page.py` (named by digest in [the trials' index](../../README.md)): a headless agent with no memory, Skill or hook, in a
room holding only the repository at the bank's pin, before any item was shown to a subject.

| Page                    | Statements | Tool calls | Seconds | Cost by the agent's count | Paths named outside the room |
| ----------------------- | ---------- | ---------- | ------- | ------------------------- | ---------------------------- |
| [ETHOS](ethos.md)       | 50         | 32         | 405     | 1.45 USD                  | 0                            |
| [AIGW CLI](aigw-cli.md) | 47         | 33         | 1065    | 1.45 USD                  | 0                            |

Both holders ran as `claude-opus-5-5`. Every citation of both pages names a file that exists at the pin with at
least the cited lines (50 and 49 citations checked by script); no one judged whether the lines support the
statements. Two earlier attempts wrote no page: the first had no budget and was cut off after 25 minutes, the
second gave its page as an answer of which only the end was kept. The pages are as the holders gave them, but for
the formatter's spacing.
